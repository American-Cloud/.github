## 🦅 Who We Are

American Cloud is infrastructure for builders who value **ownership, independence, and resilience**. We exist because too much of the modern internet is built on platforms that don't share those values — platforms that can suspend your account, change their policies overnight, or quietly throttle your business.

We're proudly American — not as a slogan, but as a philosophy: free enterprise, free expression, free markets.

> *You should control your software. You should control your data. You should control your future.*

## 🏗️ What We Build

This GitHub organization contains open-source tooling, SDKs, integrations, and documentation for the American Cloud platform.

| Product | Description |
|---|---|
| ☁️ **Cloud Compute** | Virtual machines powered by fast CPUs, RAM, and SSD |
| 🗄️ **Managed Databases** | Fully managed PostgreSQL, MySQL, and Redis |
| 🪣 **Object Storage** | S3-compatible storage at $0.02/GB — no egress fees |
| 💾 **Block Storage** | SSD and NVMe volumes, resizable and portable |
| ⚙️ **Kubernetes** | Managed clusters for containerized workloads |
| 🌐 **DNS** | Free DNS management — no caps on zones or records |
| ⚖️ **Load Balancing** | Traffic distribution with built-in DDoS protection |
| 📈 **Auto-Scaling** | Scale instances based on CPU, RAM, or custom metrics |
| 🌐 **Managed WordPress** | Fast, secure, fully managed WordPress hosting |
| 🏢 **OpenColo Data Center** | Silicon Valley colocation, 2N power, carrier-neutral |

## 🤝 Contributing

We welcome contributions from the community. Before opening a PR:

1. Check the open issues for existing discussions
2. Open an issue to propose significant changes before building
3. Follow the coding standards in each repo's `CONTRIBUTING.md`
4. Keep PRs focused — one concern per pull request

All contributors are expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
